# Word Wise

**Word Wise** is a web-based text analysis tool that helps you optimize your writing for social media, especially Twitter/X. It provides real-time word and character counts, informs you how close you are to the free or paid user character limit, and instantly flags forbidden words.

## Features

- [x] Live word and character counting
- [x] Simulated Twitter/X Free and Paid posting scores
- [x] Forbidden word detection with instant alerts
- [x] Clean, responsive React-based UI
- [x] User-friendly prompts and feedback

## Technologies Used

- HTML
- CSS
- JavaScript
- React
